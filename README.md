# Data Analyst Portfolio — Chetan Sawale

Two end-to-end projects on one realistic dataset (ATM transaction logs from a cash-management
operation — the domain I work in daily as a Reports Executive at Hitachi Cash Management Services).

| Project | Tools | What it shows |
|---|---|---|
| [`atm-data-quality-sql/`](atm-data-quality-sql/) | SQL (SQLite), CSV | Profiling messy data → documented cleaning rules → business answers (failure rates, worst ATMs, cash outflow, peak hours) |
| [`atm-cash-demand-eda/`](atm-cash-demand-eda/) | Python, pandas, matplotlib, Jupyter | Exploratory analysis with 5 charts: demand trend, hourly patterns, regional failures, maintenance priority list, amount distribution |

**Skills demonstrated:** data profiling & validation, data cleaning (deduplication, label standardisation,
out-of-range handling), SQL (window functions, CTEs, aggregations), pandas EDA, matplotlib visualisation,
and writing findings as decisions — not just numbers.
